# My Blog

A blog built with [Krems](https://github.com/mreider/krems) and managed by [StaticPress](https://staticpress.me).

## Setup

This repository is automatically deployed to GitHub Pages using the Krems deploy action.

## Local Development

1. Download Krems from the [releases page](https://github.com/mreider/krems/releases)
2. Run `krems --run` to preview at localhost:8080

## Structure

- `config.yaml` - Site configuration
- `*.md` files - Blog posts with YAML frontmatter
- `images/` - Image assets
